Robot Rescue

Recover the key, dodge the hazard, and reach the exit before your battery runs out.

MISSION CONTROL

Use the arrow keys or buttons. Coordinates start at (0,0), top left. KEY: (2,1). HAZARD: (3,2). EXIT: (5,5). Invalid moves cost no energy. Each valid move costs 1; the hazard costs 3 extra. You need the key to escape.
